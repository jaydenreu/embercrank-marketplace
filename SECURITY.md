# Security

Report a suspected vulnerability privately to contact@embercrank.com. Include the connector version, affected host, reproduction steps and impact. Do not include provider credentials, Embercrank tokens, customer prompts, source code or other customer content in the report.

The connector must be installed from the tagged repository and verified against `checksums.sha256`. Provider credentials stay with the official provider tools. Embercrank credentials use the connector's local credential store and must never be committed to a project or marketplace repository.

This public connector is intentionally separate from Embercrank's private routing service. Please do not use a suspected vulnerability to access another account, interrupt the service or extract customer data.
